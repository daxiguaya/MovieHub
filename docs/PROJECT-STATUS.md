## 当前产品范围

- 榜单：Douban Top 250，以及已导入的 2025 年四份年度榜单。
- 搜索：本地影片目录搜索与筛选；另有 TMDB 在线发现。
- 详情：展示可用元数据、来源标识、海报和外部链接。
- 评分展示：当前 UI 以 IMDb 评分为影片评分；TMDB 评分不作为影片评分展示。TMDB 仍用于发现和元数据。
- 收藏：本地目录与在线发现收藏入口共存，按后端各自的数据机制保存。
- Xiaoya：提供跳转到已配置的小雅搜索页面；MovieHub 不承担下载、播放或媒体库管理。

## 已明确下线 / 不纳入当前范围

- 豆瓣实时热门榜、豆瓣高分榜：因对应接口被 robots.txt 禁止访问，已停止采集并从产品入口移除。不得把旧采集脚本当作当前运维流程，也不得尝试绕过访问限制。
- 不新增下载、播放、媒体库管理、额外账号系统或重型基础设施。
- 2026 年度榜单：待官方分类及榜单发布后再单独核验；不以空榜定义或旧计划视为已发布数据。

## 验收边界与维护注意事项

- 生产数据审计、前端镜像部署和健康检查已确认；这不等同于最近对所有搜索、收藏、小雅跳转路径逐一重新进行人工验收。
- 任何数据库迁移前，先确认 schema、备份及回滚方案；禁止在现有生产库上执行初始化覆盖。
- 不要用 MovieHub 数据库替代 Douban Scout 数据库；Scout 只允许只读导入。
- NPM 配置变更、NPM reload/restart、其他容器重启、生产数据导入均属于独立操作，不包含在普通代码更新中。没有明确必要和授权，不执行。
- 不提交生产数据库、备份、API key、私有环境文件或 IMDb 派生数据集。

## 后续维护原则

1. 优先修复可复现的缺陷和安全问题，不为追求进度百分比而扩展功能。
2. 新增榜单来源前先核验来源授权、robots.txt、稳定性和数据许可。
3. 2026 年榜单只有在官方来源实际发布并核验后再导入。
4. 任何生产操作先备份、预检、明确影响范围和回滚方式。
5. 当前没有必须立即执行的数据库迁移或生产部署任务。
